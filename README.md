# MasterModel
#### Minecraft datapack  
数据包版本：V 1.3.3x  
适用版本：1.21.11  

### 数据包简介
旨在增加minecraft游玩难度的数据包。加强了敌怪和世界难度，移除了部分合成配方以至于玩家只能在地图中找到这些物品，增加了玩家装备的可升级项，让玩家可以拥有更强力的装备和更丰富的体验。  

### 主要功能和变化
#### 物品
- 移除了工作台和所有工作方块的合成配方
- 移除了用木头合成木棍的合成配方
- 移除了铁质护甲和钻石资护甲的合成配方
- 合成的铁质工具和钻石质工具将带有“劣质的”词条（耐久折半）
- 附魔台和铁砧可以在领地府邸的新房间中被找到
- 铁砧能够在与铁块合成以获得修复
