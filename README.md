# MasterModel
#### Minecraft datapack  
数据包版本：V 1.3.3x  
适用版本：1.21.11  

### 数据包简介
旨在增加minecraft游玩难度的数据包。加强了敌怪和世界难度，移除了部分合成配方以至于玩家只能在地图中找到这些物品，增加了玩家装备的可升级项，让玩家可以拥有更强力的装备和更丰富的体验。  

### 主要功能和变化
#### 物品合成
- 移除了工作台和所有工作方块的合成配方
- 移除了用木头合成木棍的合成配方
- 移除了铁质护甲和钻石资护甲的合成配方
- 合成的铁质工具和钻石质工具将带有“劣质的”词条（耐久折半）
- 更改了营火的合成配方，现在可以在背包中直接被合成
- 添加了新的石矛合成配方，现在可以在背包中直接被合成
- 铁砧能够在与铁块合成以获得修复
- 减少了通过配方合成火把的数量变至 1
- 铜火把现在使用铜锭合成（而不是铜粒）
- 增加了熔炉的烧炼和烹饪时间加长，现在需要消耗更多的燃料
- 增加烟熏炉和高炉的使用时间到原版游戏的水平
- 增加了使用熔炉，烟熏炉和高炉获得的经验
- 减少了营火烹饪的时间
- 现在可以用营火烧制粗铜矿

#### 结构与战利品
- 现在可以在不同结构的战利品箱子中找到带有“普通的 优质的 传奇的”词条的装备和工具
- 附魔台和铁砧可以在领地府邸的新房间中被找到 （当然它们不能合成）
- 首次击杀凋灵将掉落“Hero Sword”
- 末影人和烈焰人只将在被“Hero Sword”杀死时掉落末影珍珠和烈焰棒
- 怪物掉落的武器可能带有“怪物的”修饰词特殊加成
- 现在可以用下界合金稿开采强化深板岩

#### 生物更改
- 大幅增加了敌怪的伤害
- 大幅增加了大部分敌怪的索敌范围
- 增加了大部分敌怪的移动速度
- 增加了部分怪物持有武器的概率
- 增加了怪物武器拥有附魔的概率
- 持有武器的怪物能够破开盾牌

- 敌怪有一定概率会获得精英怪的特殊加强
- 增加了恶魂火球和苦力怕的爆炸威力
- 小幅减少了苦力怕的爆炸时间

- 增加了狼，铁傀儡和部分中立生物的血量和伤害

- 在与凋零战斗时会扣除玩家5点血量上限
- 在与末影龙战斗时会扣除玩家10点血量上限

#### 锻造模板更改  
锻造模板可以在锻造台上搭配合适的材料用于升级盔甲，武器和工具。  

- 不同的锻造模板升级会获得不同的效果加强
- 低级的锻造模板将由7个铜锭作为复制材料（而不是钻石）
- 适用的盔甲和工具类型以及升级材料会显示在模板的详细信息上
- 盔甲纹饰升级不会让装备获得对应的增强效果
- 多次锻造会覆盖上一次锻造的效果

#### 盔甲升级

##### 犰狳强化
- 可用于硬质盔甲 | 升级模板：沙丘锻造模板 升级材料：犰狳鳞甲
- 增加1点盔甲韧性

##### 海龟强化
- 可用于硬质盔甲 | 升级模板：海岸锻造模板 升级材料：海龟鳞甲
- 增加1点护甲值

##### 肋骨强化
- 可用于锁链盔甲 | 升级模板：肋骨锻造模板 升级材料：骨头
- 大幅增加盔甲韧性
- 增加了火焰在身上燃烧的时间
- 套装奖励：潜行时快速消耗饥饿恢复血量


##### 回响强化
- 可用于硬质盔甲 | 升级模板：幽静锻造模板 升级材料：回响碎片
- 中幅增加了盔甲韧性
- 中幅增加了护甲值
- 大幅减少了耐久值
- 装备后会获得持续的黑暗效果
  
##### 幽静强化
- 可用于硬质盔甲 | 升级模板：幽静锻造模板 升级材料：强化深板岩
- 中幅增加了盔甲韧性
- 中幅增加了护甲值
- 大幅减少了耐久值
- 增加了在灵魂沙和蜂蜜块上的通行能力
  
##### 下界合金强化
##### 眼眸强化
- 可用于头盔 | 升级模板：眼眸锻造模板 升级材料：末影珍珠
- 穿戴后潜行会高亮附近的敌怪，动物和玩家
- 潜行时会获得短暂的黑暗效果
