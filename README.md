# ⚔️ MasterModel
> **Minecraft 高难度硬核生存数据包**

---

## 📖 数据包简介
旨在增加 Minecraft 游玩难度的数据包。加强了敌怪和世界难度，移除了部分合成配方，迫使玩家只能在地图中探索获取关键物品。同时增加了装备的可升级项，带来更丰富的挑战与成长体验。

---

## ⚙️ 主要功能与变化

### 🛠️ 物品合成
- 移除工作台及所有功能性方块的合成配方
- 移除使用木头合成木棍的配方
- 移除铁质、钻石质护甲的合成配方
- 合成的铁质/钻石质工具/弓弩/盾牌将带有 **“劣质的”** 词条（耐久度折半）
- 使用合成配方修复时，将会回满物品的耐久。如果物品属于铁质/钻石质工具/弓弩/盾牌则将带有 **“普通的”** 词条
- **新增/调整**：
  - 营火、石矛现可在背包中直接合成
  - 铁砧可通过与铁块合成进行修复
  - 火把合成产出减至 1 根；铜火把改用铜锭合成（原为铜粒）
<img width="312" height="127" alt="README1" src="https://github.com/user-attachments/assets/92023723-10f4-4c72-9199-8ef0af5ee093" />

- **熔炉机制**：
  - 熔炉、烟熏炉、高炉烧炼时间延长，消耗更多燃料（烟熏炉/高炉恢复至原版水平）
  - 上述方块获得的经验值提升；营火烹饪时间缩短，且可用于烧制粗铜矿

### 🏛️ 结构与战利品
- 战利品箱中可找到带 **“普通的 / 优质的 / 传奇的”** 词条的装备与工具
- 村庄皮匠屋箱子中可找到带词条的皮革套装
- 林地府邸新增房间，内含**无法合成**的附魔台与铁砧
- **BOSS 专属**：
  - 首次击杀凋灵掉落 **“Hero Sword”**
  - 末影人（末影珍珠）与烈焰人（烈焰棒）仅能被 Hero Sword 击杀时掉落
- 怪物掉落的武器可能附带 **“怪物的”** 修饰词特殊加成
- 下界合金稿现可开采强化深板岩

### 👾 生物更改
- **基础强化**：大幅提升敌怪伤害、索敌范围、移动速度；提高怪物持械及附魔概率；持械怪物可破盾
- **精英怪**：敌怪有概率获得**精英怪**特殊加强
- **环境威胁**：恶魂火球与苦力怕爆炸威力增强；苦力怕爆炸时间略微缩短
- **中立单位**：狼、铁傀儡等中立生物血量与伤害提升
- 幻翼伤害调整为 **19.5**（困难模式）
- **Boss战优化**：
  - 凋灵：
    - 存在时扣除玩家 10 点血量上限
    - 生成时会生成一个战斗平台
    - 免疫闪电伤害；最大生命 **450**；无法用笼子跳关
    - 在灵魂沙峡谷（Y=32~110）召唤时锁定活动范围，并强制附近铁傀儡 / 狼 / 狐狸仇恨玩家
    - 仅在灵魂沙峡谷击败凋零，可获得 **“勇者之证”** 并掉落英雄之剑
  - 末影龙：
    - 存在时扣除玩家 10 点血量上限
    - 末影龙现在有多个阶段，每个阶段会有不一样的行为（详见更新日志）
    - 不会受到除玩家伤害以外的任何伤害
  - 远古守卫者：
    - 存在时扣除玩家 5 点血量上限
- **村民交易优化**：（详见更新日志）
  - 修改了一些村民的交易项，交易顺序，交易价格
  - 不同群系的村民也可能会出售一些不同的物品
  - 大师等级的图书馆管理员会出售每次交易都随机的附魔书
  - 流浪商人会出售丛林探险家地图和沙漠探险家地图等
  - 流浪商人会出售手持时可以增加移速的”登山杖“
  - 村民出售的铁质 / 钻石工具、弓、弩带有 **“普通的”** 修饰；沼泽与丛林村民则带有 **“优质的”** 修饰
 
### ⚔️ 战斗更改
- 重做了盾牌功能：
  - 现在修饰词的盾牌具有不一样的格挡表现，耐久值和耐久消耗速度
  - 现在盾牌只能抵挡一定的伤害，超出的部分只能抵挡50%
  - 现在盾牌的防御角度仅有90度

### 🏃 玩家更改
- 摔落伤害增加
- 受伤消耗饥饿值增加
- 燃烧时间延长
- 基础击退力提升
- 前往地狱上层将会扣血

## 🏆 成就与天象

### 🎯 成就系统
> 本包中**必须击败凋灵**才能获得末影之眼，成就系统旨在引导通关流程。

- 获得木棍解锁首个成就 **“MasterModel”**
- 获得 **“Hero Sword”** 需在灵魂沙峡谷 (Y=30~100) 内触发
- **“天有吉时”** 进度位置从 MasterModel 移动至 **adventure**
- **“远古村民?!”**：与装扮为沼泽 / 丛林的村民完成一次交易（位于原版「僵尸科医生」之后）
- **“上古村落”**：获得古迹废墟探险家地图（位于「村庄?!」之后）
- **“深暗指引”**：获得古代城探险家地图（位于「上古村落」之后）

### 🌦️ 天气更改
- **可怕的雷暴**：全怪物加强，苦力怕强制转化为**闪电苦力怕**
- **史莱姆雨**：天空降落史莱姆，概率发生于满月后的第一个正午
- **新增道具**：合成 **“晴天钟 (Clear Clock)”** 以预测天象

## 📦 使用指南

### 安装步骤
1. 将数据包完整文件夹放入世界 `datapacks` 目录：
.minecraft\saves[世界名称]\datapacks
